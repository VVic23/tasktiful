# Features

## MVP Features

## Authentication

- Google login
- Secure sessions
- Protected user data


## Tasks

Users can:

- Create tasks
- Edit tasks
- Delete tasks
- Complete tasks
- Archive tasks


## Task Properties

Each task supports:

- Title
- Description
- Priority
- Due date
- Due time
- Category
- Tags
- Estimated duration


## Views

## List View

Display tasks ordered by:

- Due date
- Priority
- User preference


## Calendar View

Display tasks by:

- Day
- Week
- Month


## Backlog

Tasks without due dates.

Used for:

- Ideas
- Future work
- Low urgency items


## Organization

- Categories
- Tags
- Favorites
- Filters
- Search
